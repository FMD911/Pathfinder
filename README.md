# Pathfinder

A free, single-file career quiz for people deciding what to do next, with a focus on the Serbian job market.

**How it works**
- 20 questions are drawn at random from a bank of 38. Answer order is shuffled, so every run is different.
- Each question has five answers, one per type: Creator, Thinker, Helper, Builder, Leader. A "Neutral" option doesn't count toward any type.
- Results show your type percentages and ranked jobs with a compatibility estimate, pros and cons, by experience level (none, junior, senior).
- Includes tips for finding real jobs in Serbia and spotting fake listings.

**Run it**
Open `index.html` in a browser. No build step, no dependencies.

**Customise**
Edit the `Q` (questions) and `JB` (jobs) arrays at the top of the script in `index.html`.

**Disclaimer**
This is not a validated psychological test, and fit percentages are estimates. Job notes are general guidance; verify details yourself.
